# Shell, I/O Redirections and Filters

0-hello_world: Prints Hello, World followed by a newline.

1-confused_smiley: Prints a confused smiley.

2-hellofile: Displays the content of /etc/passwd.

3-twofiles: Displays the contents of /etc/passwd and /etc/hosts.

4-lastlines: Displays the last 10 lines of /etc/passwd.

5-firstlines: Displays the first 10 lines of /etc/passwd.

22-users_and_homes: Displays users and their home directories, sorted alphabetically.

6-third_line: Displays the third line of the file iacta.

7-file: Creates a file with a special-character name containing Best School.

8-cwd_state: Saves the output of ls -la to ls_cwd_content, overwriting existing content.

9-duplicate_last_line: Appends the last line of iacta to the same file.

10-no_more_js: Deletes all regular .js files in the current directory and subdirectories.

11-directories: Counts all directories and subdirectories, including hidden ones, excluding the current directory.

12-newest_files: Displays the 10 newest entries in the current directory.

13-unique: Displays words that appear exactly once, sorted alphabetically.

26-the_biggest_fan: Displays the 11 most active hosts from TSV web server logs.

25-acrostic: Decodes an acrostic using the first character of each line.

23-empty_casks: Lists empty files and directories by name.
24-gifs: Lists GIF filenames without extensions, sorted case-insensitively.

14-findthatword: Displays lines containing root from /etc/passwd.

16-whatsnext: Displays lines containing root and the following three lines.

17-hidethisword: Displays lines from /etc/passwd that do not contain bin.

18-letteronly: Displays lines from sshd_config starting with a letter.

19-AZ: Replaces A with Z and c with e from standard input.

20-hiago: Removes all lowercase c and uppercase C characters from input.
