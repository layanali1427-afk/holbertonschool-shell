# Shell, Init Files, Variables and Expansions

0-alias: Creates an alias named ls.

1-hello_you: Prints hello followed by the current Linux username.

2-path: Adds /action to the end of PATH.

3-paths: Counts non-empty directories listed in PATH.

4-global_variables: Lists all environment variables.

5-local_variables: Lists local variables, environment variables, and shell functions.

6-create_local_variable: Creates a local variable BEST with the value School.

7-create_global_variable: Creates an environment variable BEST with the value School.

8-true_knowledge: Adds 128 to TRUEKNOWLEDGE and prints the result.

9-divide_and_rule: Divides POWER by DIVIDE and prints the result.

10-love_exponent_breath: Raises BREATH to the power of LOVE.

11-binary_to_decimal: Converts a binary number to decimal.
